# Публикация профильного README

GitHub показывает README на главной странице профиля, если создать публичный репозиторий с именем, полностью совпадающим с именем пользователя.

Для подготовленного профиля:

1. Открой https://github.com/new.
2. В поле Repository name введи `agentbonjovi`.
3. Выбери **Public**.
4. Не добавляй README, `.gitignore` или лицензию при создании репозитория.
5. Нажми **Create repository**.
6. Загрузи в корень репозитория `README.md` и папку `assets` из этой папки.

После публикации проверь главную страницу https://github.com/agentbonjovi. GitHub должен показать блок README над вкладкой активности.

Перед публикацией можно заменить формулировки в секциях `current_focus`, `toolbox` и `how_i_lead`. Текст не содержит выдуманных компаний, проектов, стажа или показателей.

Если имя пользователя отличается от `agentbonjovi`, переименуй репозиторий и замени три ссылки внизу README.
